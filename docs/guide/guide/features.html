Features & Navigation Guide ​

This section details every core feature of MindMap Pad, how to navigate the application to access them, and usage instructions.

1. Infinite Canvas & Viewport ​

Navigate and explore your workspace freely without spatial boundaries.

How to Navigate & Use ​

  • Panning: Click and drag anywhere on the empty canvas background, or use two-finger trackpad swipe gestures.
  • Zooming: Scroll the mouse wheel up to zoom in and down to zoom out. The view centers smoothly on your cursor pointer.
  • Fit to View: Access map controls from the top menu to re-center and fit all nodes into view.

2. Node Management & Editing ​

Create, organize, and structure your thoughts hierarchically.

How to Navigate & Use ​

  • Adding Nodes: Press Enter to add a sibling node or Tab to add a child node to the currently selected node.
  • Editing Text: Double-click directly on any node box to enter inline text editing mode. Press Enter to save or Escape to cancel.
  • Deleting Nodes: Select a node and press Delete or Backspace.

3. Node Contextual Menu ​

Access quick actions and management tools instantly via right-click interaction on any node.

How to Navigate & Use ​

  • Opening the Menu: Right-click on any node box on the canvas to open the floating contextual menu.
  • Available Actions: From the contextual menu, you can add child or sibling nodes, delete the node, open styling options, manage tags and icons, or attach notes and external links.

4. Color Styling ​

Personalize your mind map nodes with custom background, border, and text colors.

How to Navigate & Use ​

  • Selecting Colors: Select a node and open the color picker from the toolbar or right-click context menu.
  • Customization: Choose custom background, border, and text colors to visually categorize and highlight important nodes.

5. Tags ​

Categorize and filter your ideas using descriptive tags attached to nodes.

How to Navigate & Use ​

  • Adding Tags: Open the tag manager from the node's context menu or properties panel.
  • Organization: Assign multiple tags to nodes to group related concepts across different branches of the mind map.

6. Icons ​

Enhance visual recognition with emoji or icon indicators on your nodes.

How to Navigate & Use ​

  • Adding Icons: Select a node and open the icon selector from the context menu.
  • Visual Cues: Attach relevant icons to instantly communicate status, categories, or types of thoughts at a glance.

7. Notes ​

Attach detailed markdown-formatted notes to any node for expanded context and documentation.

How to Navigate & Use ​

  • Opening Notes: Click the note badge on any node or open the note editor from the context menu.
  • Markdown Support: Write and format rich markdown notes directly within the built-in modal editor.

8. Links ​

Connect nodes to external web pages and references for quick access.

How to Navigate & Use ​

  • Adding Links: Open the link manager or click the link badge on a node to attach an external URL.
  • Quick Access: Click the node link badge or shortcut to navigate directly to the referenced webpage.

9. History & Undo/Redo ​

Never worry about mistakes with full command history tracking.

How to Navigate & Use ​

  • Use standard keyboard shortcuts (Ctrl+Z / Cmd+Z for Undo, Ctrl+Y / Cmd+Y or Ctrl+Shift+Z / Cmd+Shift+Z for Redo) or access history controls from the main menu.
